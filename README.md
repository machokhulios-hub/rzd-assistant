# РЖД Ассистент - сайт

Статический сайт для поиска по нормативным документам по ключевым словам, открытия документов на нужной странице, калькуляторов (отдых в бригаднике, справка ВУ-45) и учёта часов. Работает без сервера: поиск выполняется прямо в браузере по индексу, который заранее собирает скрипт `build.py`. Учёт часов хранит поездки только в браузере пользователя на его устройстве.

## Как добавить документ

1. Откройте папку `documents` в репозитории на сайте GitHub.
2. Нажмите **Add file** -> **Upload files**.
3. Перетащите файлы (PDF, DOCX, TXT) и нажмите **Commit changes**.

Через 1-3 минуты сайт обновится сам.

Чтобы удалить документ, удалите файл из папки `documents` тем же способом.

## Ограничения

- Сканы без текстового слоя в поиск не попадают: файл будет в списке документов, но искать по нему нельзя. Нужен PDF с распознанным текстом.
- Старый формат `.doc` не поддерживается. Сохраните файл как `.docx` или PDF.
- Через сайт GitHub можно загрузить файл до 25 МБ, через git - до 100 МБ.
- Сайт на GitHub Pages открыт всем в интернете, и на бесплатном тарифе репозиторий тоже должен быть публичным. Не кладите документы, которые нельзя публиковать.

## Первая публикация на GitHub

1. Создайте публичный репозиторий.
2. Загрузите в него содержимое этой папки, включая скрытую папку `.github` (в Finder скрытые файлы показывает Cmd+Shift+точка).
3. В репозитории откройте **Settings** -> **Pages** и в поле **Source** выберите **GitHub Actions**.
4. Дождитесь зелёной галочки во вкладке **Actions**.
5. Адрес сайта будет вида `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Проверка на своём компьютере

```bash
pip install -r requirements.txt
```

```bash
python build.py
```

```bash
python -m http.server 8090 --directory public
```

Затем откройте http://localhost:8090.

## Как устроено

- `documents/` - исходные документы.
- `build.py` - читает документы, режет текст на фрагменты и собирает папку `public/`: страницу, сами файлы и поисковый индекс.
- `web/index.html` - страница сайта: поиск, учёт часов, калькуляторы. Разбор слов в ней повторяет `build.py` - менять их нужно вместе.
- `.github/workflows/pages.yml` - сборка и публикация при каждом изменении в ветке `main`.

Калькуляторы находятся в `web/index.html` в разделе «Калькулятор»; после правки сайт пересоберётся сам.
