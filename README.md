# РЖД Ассистент - сайт

Статический сайт для поиска по нормативным документам по ключевым словам, открытия документов на нужной странице, калькуляторов (отдых в бригаднике, справка ВУ-45) и учёта часов. Работает без сервера: поиск выполняется прямо в браузере по индексу, который заранее собирает скрипт `build.py`. Учёт часов хранит поездки только в браузере пользователя на его устройстве.

## Как добавить документ

1. Положите файлы (PDF, DOCX, TXT) в нужную папку внутри `documents`. Каждая папка - плитка в разделе «Документы»: `documents/3. Тормоза/...` попадёт в папку «Тормоза». Номер в начале названия папки задаёт только порядок (1, 2, ... 9, 9.1, папки без номера - в конце), на сайте его не видно. Новая папка появится на сайте сама, даже пустая (чтобы git сохранил пустую папку, в ней лежит файл `.gitkeep`).
2. Запустите публикацию:

```bash
./publish.sh
```

Скрипт собирает сайт и выкладывает его на GitHub Pages (ветка `gh-pages`). Через минуту сайт обновится. Загрузка файла через сайт GitHub сайт сама не обновит.

Чтобы удалить документ, удалите файл из `documents` и запустите публикацию заново.

## Mini App в Telegram

Этот же сайт открывается внутри Telegram-бота как Mini App - отдельно собирать ничего не нужно, после `./publish.sh` обновляется и сайт, и Mini App.

Подключение к боту (один раз, в @BotFather):

1. `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Отправьте адрес сайта: `https://machokhulios-hub.github.io/rzd-assistant/`, затем название кнопки, например `Открыть`.
3. Дополнительно, чтобы приложение открывалось из профиля бота и по ссылке `t.me/<бот>/app`: `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → тот же адрес.

Что меняется внутри Telegram:

- тема (светлая/тёмная) - как в Telegram, пока её не переключили в настройках;
- кнопка «Назад» Telegram возвращает в предыдущий раздел, свайп вниз не сворачивает приложение при прокрутке;
- документы и расписание электричек открываются в браузере;
- поездки, сроки, отпуск, закладки, отметки билетов, маршруты и расчёты сохраняются в облаке Telegram (CloudStorage) и видны на всех устройствах пользователя;
- выгрузка месяца в таблицу на телефоне - через «Поделиться», а если нельзя - таблица копируется в буфер обмена.

У браузера и Telegram разные хранилища. Чтобы перенести данные, в «Настройках» есть «Перенос данных»: на одном устройстве «Скопировать код» (или «Сохранить в файл»), на другом - вставить код и «Перенести» (или «Загрузить файл»). Поездки, сроки, закладки и отметки билетов добавляются к уже записанным без повторов, отпуск и расчёты заменяются.

## Свой хостинг со входом

На GitHub Pages сайт открыт всем. Чтобы пускать на сайт только зарегистрированных пользователей, его выкладывают на обычный хостинг с PHP 8.1+ и MySQL (Beget, Timeweb, REG.RU и т. п.). Код входа лежит в папке `server/`.

### Как выложить

1. Соберите сайт для хостинга:

```bash
./hosting.sh
```

Получится папка `hosting/` и архив `rzd-hosting.zip` с тем же содержимым.

2. В панели хостинга создайте базу MySQL и запишите её имя, пользователя и пароль.
3. Загрузите содержимое архива в корень сайта (обычно `public_html` или `www`) - через файловый менеджер панели («Загрузить» → «Распаковать») или по FTP. Скрытые файлы `.htaccess` тоже должны попасть на хостинг.
4. В папке `_srv` на хостинге скопируйте `config.sample.php` в `config.php` и впишите данные базы, адрес сайта (`site_url`) и почту отправителя (`mail_from`).
5. Откройте сайт. Пока пользователей нет, появится «Настройка сайта» - создайте учётную запись администратора. Таблицы в базе создадутся сами.
6. Включите на хостинге HTTPS (бесплатный сертификат Let's Encrypt есть в панели почти у всех): без него пароли передаются открытым текстом.

Обновление сайта: снова `./hosting.sh` и загрузка архива поверх. Файл `_srv/config.php` в архив не входит и не перезапишется.

### Как устроен вход

- Все запросы к страницам, документам и данным проходят через `gate.php` (правила в `.htaccess`). Без входа открываются только страницы `auth/` и значки сайта. Даже по прямой ссылке файл без входа не скачать.
- Регистрация - по почте и паролю. Режим задаётся в `_srv/config.php` (`registration`):
  - `approve` - по заявке: пользователь регистрируется, подтверждает почту, администратор одобряет. Так настроено по умолчанию;
  - `open` - вход сразу после подтверждения почты;
  - `closed` - регистрации нет, пользователей добавляет администратор.
- После входа в шапке сайта рядом с настройками появляется значок учётной записи (у администратора красная точка - новые заявки). Администратор: значок или «Настройки» → «Пользователи» (или `auth/admin.php`). Там видны заявки. Пользователя можно одобрить, заблокировать, удалить, сделать администратором, добавить нового и выдать ссылку для смены пароля. Ссылку можно переслать самому - это выручает, если письма не доходят.
- Письма (подтверждение почты, восстановление пароля, заявки) отправляются через `mail()` хостинга. Если хостинг писем не отправляет, поставьте `'verify_email' => false`: одобрение администратором тогда заменяет подтверждение почты, а пароли меняются по ссылкам из админки.
- Вход помнится на устройстве 90 дней (`session_days`). Пароли хранятся только в виде хэша. После 10 неверных паролей к одной почте вход на 15 минут закрывается. После смены пароля входы на других устройствах сбрасываются.
- Выход - «Настройки» → «Выйти»: заодно удаляется всё, что было скачано для работы без сети.
- Telegram Mini App работает и на своём хостинге: в @BotFather укажите новый адрес сайта, войти нужно будет один раз внутри Telegram.

Пока сайт открыт и на GitHub Pages, закрытый вход ничего не закрывает. После переезда отключите GitHub Pages (Settings → Pages) или сделайте репозиторий приватным - на бесплатном тарифе Pages для приватного репозитория не работает.

## Сканы

В скане нет текста, поэтому поиск по нему не работает. Текст можно набрать вручную и сохранить в `documents/_text/` под тем же именем, что у PDF, но с расширением `.txt`. Страницы отделяются строками вида `=== стр. 1 ===`. Тогда поиск находит скан и открывает его на нужной странице.

## Ограничения

- Сканы без текстового слоя в поиск не попадают, пока для них не набран текст (раздел «Сканы»).
- Старый формат `.doc` не поддерживается. Сохраните файл как `.docx` или PDF.
- Через сайт GitHub можно загрузить файл до 25 МБ, через git - до 100 МБ.
- Сайт на GitHub Pages открыт всем в интернете, и на бесплатном тарифе репозиторий тоже должен быть публичным. Не кладите документы, которые нельзя публиковать.

```bash
pip install -r requirements.txt
```

```bash
python build.py
```

```bash
python -m http.server 8090 --directory public
```

Затем откройте http://localhost:8090.

## Как устроено

- `documents/` - исходные документы по папкам-разделам; `documents/_text/` - набранный вручную текст сканов.
- `publish.sh` - сборка и публикация.
- `build.py` - читает документы, режет текст на фрагменты и собирает папку `public/`: страницу, сами файлы и поисковый индекс.
- `web/index.html` - страница сайта (она же Mini App в Telegram): поиск, закладки, учёт часов и оценка зарплаты, калькуляторы, сроки, билеты, настройки, инструменты (калькулятор, часы с московским временем, таймер обратного отсчёта). Разбор слов в ней повторяет `build.py` - менять их нужно вместе.

- `web/tickets.json` - билеты для раздела «Билеты» (номер билета и вопросы).
- `web/sw.js`, `web/manifest.webmanifest`, `web/icon-*.png` - работа без интернета и значок приложения.

Калькуляторы находятся в `web/index.html` в разделе «Калькулятор»; после правки пересоберите и опубликуйте сайт.
