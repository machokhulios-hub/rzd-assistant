# Исправления для документов единого стиля: «было -> стало», по одному на строку.
# «Было» пишется как в исходном документе; заменяются только целые слова и фразы.
# Слово с маленькой буквы исправляется и в начале предложения.

# орфография: принятый термин - «технико-распорядительный акт» (ТРА)
техническо-распорядительные -> технико-распорядительные
техническо-распорядительных -> технико-распорядительных

# пунктуация: причастный оборот после определяемого слова выделяется запятыми
локомотивов следующих в нерабочем состоянии -> локомотивов, следующих в нерабочем состоянии
"помощник машиниста электровоза" должен знать -> "помощник машиниста электровоза", должен знать
связана с движением поездов утвержденные приказом -> связана с движением поездов, утвержденные приказом
# обстоятельство перед инфинитивом запятой не отделяется
с запрещающим показанием, стоять около -> с запрещающим показанием стоять около
# причастный оборот в середине предложения закрывается запятой
повлекших разлив нефтепродуктов для принятия мер -> повлекших разлив нефтепродуктов, для принятия мер
